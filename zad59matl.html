text-decoration: none – w CSS usuwa wszelkie domyślne dekoracje tekstu, takie jak: Podkreślenie (np. w linkach ), Przekreślenie, Linia nad tekste
text-decoration: underline – Właściwość text-decoration: underline; w CSS dodaje linię pod tekstem, co oznacza podkreślenie. Jest to powszechnie stosowana w linkach, aby wskazać, że są one klikalne. Przykład zastosowania: text-decoration: underline; zastosowany w stylach CSS dla elementu sprawia, że tekst linku jest podkreślony.
